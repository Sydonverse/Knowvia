Engineering & System Design
System Architecture & Tech Stack
Engineered for speed, strict security boundaries, and zero-cost cloud deployment.
3:35 – 4:00 (25s)
Client Tier (PWA)
React 19 + TypeScript + Vite: Ultra-fast responsive UI with a custom Vanilla CSS design system.
Service Worker (Cache v6) & Web Push: Installable on mobile/desktop; background automated class alerts.
Application Layer
Node.js & Express API: Strict JWT role-scoping and department authorization guards.
Socket.io & File Heuristics: Room isolation by dept:{slug} with an in-memory ZIP central directory scanner.
Data & Cloud Tier
Supabase PostgreSQL with Row-Level Security (RLS): Prevents unauthorized cross-department data queries.
Prisma ORM & S3 Storage: Strict type-safety, connection pooling, and authenticated material streaming.
